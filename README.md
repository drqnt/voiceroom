# VoiceRoom

Голосовой чат для своей компании: вход по нику, комнаты, музыка с YouTube,
звук игр не приглушается.

- `ios/` — приложение для iPhone (SwiftUI + LiveKit).
- `server/` — сервер ников и токенов, музыкальный бот и страница для Мака.
- `start-server.sh` — запускает всё на Маке.
- `install-iphone.sh` — ставит приложение на айфон, подключённый к Маку.
- `connect-livekit-cloud.sh` — подключает LiveKit Cloud для работы через интернет.

## 1. Запустить сервер на Маке

```bash
./start-server.sh
```

Скрипт печатает адрес сервера. Его нужно вписать в приложении: экран ника → «Сервер»
или ⚙︎ → «Сервер». С самого Мака можно зайти через браузер: http://localhost:3077.

Есть два режима:

- **Дома** (по умолчанию). Всё работает на Маке, айфоны должны быть в той же Wi-Fi.
- **Через интернет**. Голос идёт через бесплатный LiveKit Cloud, а сервер ников
  открывается в интернет через туннель Cloudflare. Включается один раз, см. раздел 3.

Мак должен быть включён, пока вы общаетесь. Пока работает `start-server.sh`, он сам
не даёт Маку уснуть, но с закрытой крышкой без зарядки Мак всё равно уснёт.

## 2. Поставить приложение на айфон

С бесплатным Apple ID приложение ставится только на айфон, **подключённый к этому Маку**,
работает **7 дней**, и таких айфонов может быть **до 3**. Через 7 дней нужно подключить
айфон и поставить ещё раз.

1. Подключи айфон кабелем, разблокируй, нажми «Доверять этому компьютеру».
2. На айфоне включи режим разработчика: Настройки → Конфиденциальность и безопасность →
   Режим разработчика (айфон перезагрузится). Если пункта нет, сначала сделай шаг 3:
   он появится после первой попытки.
3. На Маке. Перед первым запуском запиши идентификатор своей команды Apple (10 символов,
   Xcode показывает его в Signing & Capabilities) в файл `ios/team.local`: в git он не
   хранится.

   ```bash
   ./install-iphone.sh
   ```

4. Если при запуске айфон пишет «Ненадёжный разработчик»: Настройки → Основные →
   VPN и управление устройством → Apple Development → Доверять.
5. Разреши микрофон и доступ к локальной сети, когда приложение спросит.
6. Впиши адрес сервера (раздел 1) и придумай ник.

После первого раза айфон можно не подключать кабелем: скрипт найдёт его по Wi-Fi,
если айфон и Мак в одной сети.

**Друг далеко?** Без его айфона рядом с Маком бесплатно поставить не получится.
Варианты: Apple Developer Program (99 $ в год, приложение раздаётся по ссылке через
TestFlight) или собрать приложение на Маке самого друга.

## 3. Режим «через интернет»

1. Зарегистрируйся на https://cloud.livekit.io (бесплатно) и создай проект.
2. На Маке:

   ```bash
   ./connect-livekit-cloud.sh
   ```

   Откроется браузер, подтверди доступ. Ключи сохранятся в `server/.env`.
3. Перезапусти `./start-server.sh`.

**Постоянный адрес: https://voice-room.xyz.** Домен куплен в Porkbun (до 15.11.2027,
автопродление выключено), DNS — в Cloudflare. Туннель `voiceroom` настроен в
`server/tunnel.yml`, ключ туннеля лежит в `~/.cloudflared/`. `start-server.sh` сам
запускает его, если этот файл есть. Без него он открывает временный адрес
`https://что-то.trycloudflare.com`, который меняется при каждом запуске.

Важно:

- Бесплатный LiveKit Cloud даёт около 5000 участник-минут в месяц: например,
  трое по 2 часа — это 360 минут. Музыкальный бот тоже считается участником.
- Вернуться в домашний режим: удали `server/.env` и перезапусти сервер.

## 4. Комнаты

Комнаты постоянные, как каналы в Discord: они видны в списке, даже когда в них
никого нет. Список хранится на сервере (`server/data/users.json`), сначала там
одна комната «Общая».

- **Создать комнату** сразу создаёт «Комната <ник>» и заходит в неё.
- **Переименовать:** в списке смахни комнату влево (или долго нажми), внутри
  комнаты кнопка ✏️. Новое название сразу видят все, кто в ней сидит.
- **Удалить** можно только пустую комнату.

## 5. Видео и музыка (общий плеер YouTube)

В комнате, в блоке «Видео и музыка»:

- **«Найти на YouTube»** открывает YouTube внутри приложения: открой ролик и нажми
  «Включить в комнате».
- Или вставь ссылку YouTube или напиши название в поле.

Видео играет у каждого в своём встроенном плеере YouTube, а что играет и с какого
места — общее. Сервер хранит это в комнате, и плееры подстраиваются, если разошлись
больше чем на 2 секунды. Пауза, «следующее», «стоп» и очередь — общие, громкость —
у каждого своя. В приложении музыка продолжает играть, если свернуть его, пока идёт
звонок.

Ограничения:

- Видео, которые автор запретил встраивать, не включаются (сервер проверяет это
  заранее и пишет об этом).
- У кого нет YouTube Premium, у того может выскочить реклама.
- На громкой связи музыку слышно через твой микрофон, в наушниках всё нормально.
- В браузере на айфоне видео останавливается, если свернуть Safari.
- Поиск по названию работает через `yt-dlp` на Маке (только список результатов,
  без скачивания). Ссылки и «Найти на YouTube» обходятся без него.

Старый музыкальный бот (`server/music-bot.js`) больше не запускается. Если нужен,
его можно запустить вручную: `node server/music-bot.js`.

## 6. Громкость

- **Собеседник тише или громче (только у тебя):** в приложении нажми на человека
  в списке, на странице двигай ползунок рядом с ним. Запоминается по нику.
- **Свой микрофон (как тебя слышат остальные):** в приложении нажми на себя или ⚙︎ →
  «Громкость моего микрофона», на странице ползунок рядом с собой.
- **Музыка:** ползунок в блоке «Музыка», меняется только у тебя.

Настройки ⚙︎ открываются и из комнаты. Режим звука и микрофон наушников применяются
при следующем входе в комнату, громкость меняется сразу.

## 7. Проверка звука игры

1. Зайди в комнату с айфона и с Мака (http://localhost:3077).
2. На айфоне запусти игру.
3. Звук игры должен быть таким же, как без VoiceRoom, а голоса и музыка слышны поверх.
4. Если без наушников мешает эхо, в ⚙︎ переключи режим на «Звонок».
